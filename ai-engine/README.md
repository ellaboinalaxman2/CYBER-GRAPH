# Cyber Graph - AI Engine (Member 3)

## Overview

The AI Engine is **Member 3** of the Cyber Graph cybersecurity platform. It uses GraphSAGE (Graph Neural Network) to detect suspicious nodes and behaviors in the network graph.

## Responsibilities

- Data preprocessing for ML
- Feature engineering (node, edge, event, temporal features)
- Graph construction for ML
- GraphSAGE model training
- Model evaluation and validation
- Real-time anomaly detection
- Prediction and confidence scoring
- Model versioning and registry

## Quick Start

### 1. Setup

```bash
# Clone the repository
cd member3

# Create virtual environment
python -m venv venv
source venv/bin/activate  # or `venv\Scripts\activate` on Windows

# Install dependencies
pip install -r requirements.txt

# Copy environment file
cp .env.example .env
```
